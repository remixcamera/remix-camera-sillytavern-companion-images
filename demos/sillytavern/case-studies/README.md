# SillyTavern Companion Image Case Studies

These case studies separate three kinds of proof that are easy to blur together in an image-generation demo:

- a live SillyTavern and local-bridge workflow
- a real Remix.Camera output
- a generation submitted during the recorded run

Each page states exactly which of those claims the evidence supports.

## Cases

1. [Sophie: existing character to approved mirror selfie](./sophie-existing-character.md)
2. [Mila: recent chat context to a casual couch selfie](./mila-chat-context-selfie.md)
3. [Lily: one true-live selfie through SillyTavern](./lily-live-selfie.md)

## Shared product boundary

SillyTavern remains responsible for the character, model, lore, memory, and conversation. The Remix.Camera extension adds visual actions, while the local bridge keeps the Remix.Camera session credential outside the browser.

The current `v0.4.0-alpha.1` pairing flow is invite-based. The source and installer are public, but an invited Remix.Camera account is required to complete pairing.

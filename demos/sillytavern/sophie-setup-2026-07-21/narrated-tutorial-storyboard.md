## Continuous voiceover script

Already have an AI girlfriend chatbot? Don’t rebuild it just to add images. Plug in Remix.Camera.

Remix.Camera is an easy image layer for the chatbot you already have. One setup command connects it to SillyTavern. Choose an existing character profile, or create one with a name, bio, and a few reference photos. This becomes the visual identity for every image.

Your existing personality, model, chat, and memory stay exactly where they are. Remix.Camera simply supplies the visual identity and image tools.

Run Health Check, then preview the prompt before spending anything. You can verify the character, scene, model, and one-image limit first.

Now ask naturally in the conversation. Remix.Camera uses the chat context and proven visual templates to create a realistic reply that fits the moment.

The image comes back inside the chatbot, with Sophie’s face and visual identity kept consistent from her paired profile.

Keep the girlfriend chatbot you already built. Plug in Remix.Camera, and add realistic image generation in minutes.

## Production notes

- Keep all terminal and pairing-code footage free of tokens, local usernames, and private paths.
- Use Billy as the demo user throughout.
- Record the setup and no-credit preview first. Cap any new live generation at one and only run it after the prompt plan is reviewed.
- Use cursor emphasis and gentle zooms; avoid rapid pans over dense extension settings.
- Add burned-in captions so the tutorial works muted on landing pages and social feeds.
- Export a 16:9 master plus a separate 9:16 social cut with the UI reframed, not merely center-cropped.
- Keep the product promise broader than the SillyTavern implementation: the value is a reusable realistic image layer for an existing AI girlfriend chatbot.

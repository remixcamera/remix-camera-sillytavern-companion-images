## Continuous voiceover script

Your AI companion already knows what to say. With Remix.Camera, she can show you what she’s doing, too.

Start with one setup command. It installs the SillyTavern extension and opens a secure Remix.Camera pairing flow. Choose an existing character profile, or create one with a name, bio, and a few reference photos. This becomes the visual identity for every image.

Import the personalized character card. Sophie’s identity metadata connects automatically, while SillyTavern keeps control of the chat and memory.

Run Health Check, then preview the prompt before spending anything. You can verify the character, scene, model, and one-image limit first.

Now just ask naturally in the conversation. The extension uses the recent chat and searches Remix.Camera’s proven prompt templates for a strong visual match.

The result comes back inside SillyTavern, with Sophie’s face and style kept consistent from her paired profile.

Install Remix.Camera Companion Images from GitHub, pair your character once, and give every conversation a visual life.

## Production notes

- Keep all terminal and pairing-code footage free of tokens, local usernames, and private paths.
- Use Billy as the demo user throughout.
- Record the setup and no-credit preview first. Cap any new live generation at one and only run it after the prompt plan is reviewed.
- Use cursor emphasis and gentle zooms; avoid rapid pans over dense extension settings.
- Add burned-in captions so the tutorial works muted on landing pages and social feeds.
- Export a 16:9 master plus a separate 9:16 social cut with the UI reframed, not merely center-cropped.
